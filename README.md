# GLDRUBF Trading Strategy

Автоматизированная торговая стратегия для фьючерса GLDRUBF (золото) с интеграцией Telegram.

**Режим работы:** SIGNAL ONLY — стратегия анализирует рынок и отправляет сигналы в Telegram, но не совершает торговых операций.

## Запуск

### Локальный запуск стратегии

```bash
export T_SANDAPI="your_token"
export BOT_TOKEN="your_bot_token"
export TELEGRAM_CHAT_ID="your_chat_id"

python -m src.main
```

### Автоматический запуск стратегии

Стратегия запускается автоматически каждые 4 часа через GitHub Actions:
- 03:01 МСК
- 07:01 МСК
- 11:01 МСК
- 15:01 МСК
- 19:01 МСК
- 23:01 МСК

### Запуск Telegram-бота (bot.py)

Бот позволяет вручную запустить расчёт сигнала по команде `/signal`:

```bash
export BOT_TOKEN="your_bot_token"
export GH_TRIGGER_TOKEN="your_github_token"
export GITHUB_OWNER="your_github_username"
export GITHUB_REPO="your_repo_name"

python bot.py
```

**Команды бота:**
- `/signal` — запускает workflow расчёта сигнала стратегии

После получения команды бот:
1. Отправляет сообщение «⏳ Запускаю расчёт сигнала...»
2. Вызывает GitHub workflow `gold_strategy.yml`
3. Сообщает об успешном запуске или ошибке

## Параметры стратегии

Все параметры находятся в файле `config/settings.py`:

| Параметр | Значение | Описание |
|----------|----------|----------|
| `TIMEFRAME` | 4H | Таймфрейм свечей |
| `DONCHIAN_LEN` | 20 | Период канала Дончиана |
| `ATR_LEN` | 14 | Период ATR |
| `SL_ATR` | 3.0 | Stop Loss в единицах ATR |
| `TP_PCT` | 0.07 | Take Profit (7%) |
| `BE_PCT` | 0.02 | Безубыток (2%) |
| `SAR_START` | 0.03 | Начальный AF Parabolic SAR |
| `SAR_INC` | 0.02 | Шаг AF |
| `SAR_MAX` | 0.20 | Максимальный AF |
| `TARGET_TICKER` | GLDRUBF | Целевой инструмент |
| `TELEGRAM_DEBUG_MODE` | False | Режим отладки в Telegram |

## Логика работы

1. **Загрузка данных** — получаем последние 200 свечей 4H
2. **Расчет индикаторов** — ATR, Donchian Channel, Parabolic SAR
3. **Поиск позиции** — проверяем все счета на наличие позиции GLDRUBF
4. **Принятие решения**:
   - Если нет позиции → проверяем сигнал на вход (пробой Donchian)
   - Если есть позиция → проверяем условия выхода (SL, TP, SAR, BE)
5. **Отправка отчета** в Telegram

### Вход в позицию

Сигнал на вход формируется при пробое канала Дончиана:
- **LONG** — закрытие свечи выше верхней границы канала
- **SHORT** — закрытие свечи ниже нижней границы канала

### Выход из позиции

При наличии позиции проверяются условия выхода в порядке приоритета:
1. **Stop Loss** — касание уровня SL (ATR × 3.0 от цены входа)
2. **Take Profit** — достижение цели (7% от цены входа)
3. **Parabolic SAR** — разворот SAR против позиции
4. **Break-Even** — активация безубытка (2% в пользу позиции), затем выход по обновлённому SL

## Идемпотентность

Стратегия использует механизм идемпотентности для избежания дублирования сообщений:
- Хеш последней обработанной свечи сохраняется в состоянии
- Если свеча уже была обработана и состояние не изменилось — сообщение не отправляется
- При изменении позиции (открытие/закрытие) обработка выполняется всегда

Состояние хранится в файле `/tmp/gldrubf_state.json` (настраивается через переменную окружения `STATE_FILE`).

## Особенности

- **SIGNAL ONLY** — стратегия не открывает и не закрывает позиции, только анализирует и отправляет уведомления
- **UTC → МСК** — все временные метки в сообщениях конвертируются в московское время
- **Multi-account** — поиск позиции выполняется по всем счетам T-Invest
- **Stateful** — состояние сохраняется между запусками для отслеживания уровней SL/TP/BE
